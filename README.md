

## Festival selector and default

The native select replaces text search and suggestions. It preselects the earliest supported event strictly AFTER today (today itself is excluded), using the Asia/Kolkata calendar date. Events are ordered by their next occurrence. Changing the selection keeps the prompt hidden until Get prompt is pressed. Midnight/date changes refresh an untouched default; a manually chosen festival is preserved.

The offline calendar covers 2026–2031. Fixed Indian observances repeat annually. Holi, Eid al-Fitr, Thiruvonam, and Diwali use year-specific dates; Eid dates are marked expected and may change with moon sighting. After coverage ends, users can still select every festival, but the page asks for a manual selection instead of guessing the next one. Update calendar.js when new dates are published.
